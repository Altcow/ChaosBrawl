操作說明

鍵盤 P1:WASD 移動、J 攻擊、L 防禦、K 步 / 技。遊戲沒有跳躍,改用月步:E 前衝、Q 後滑、R / F 縱步上 / 下(也可 K 單按 = 前衝、K + 後 / 上 / 下),靠 HUD 青色「步力條」,不吃 MP。防禦 + 方向 + 攻擊 / K = 必殺技(吃 MP,→ 是面對的方向;每個角色有哪些招看「招式表」,遊戲中按 H 也能開)。

最強必殺技:HUD 上標示「爆氣」的金色細條是爆氣條,滿了會閃爍並出現提示,這時按 U(或 防 + 攻 + K 同時按)放最強必殺技。爆氣靠出招命中(傷害每 10 點 +2)與被打(受傷每 10 點 +3、被擊倒 +5)累積。

手機:左半邊滑動移動,把搖桿推到最外圈(左或右)會自動跑。右下的大圈是「手勢圈」:用手指一筆畫出手勢,放開才出招(點一下不會有反應)。往右畫 = 前衝、往左畫 = 後滑、往上 / 下畫 = 縱步;每個角色的 3 招必殺與最強必殺技各有專屬手勢,看首頁「招式手勢書」或遊戲中的「招式表」。圈左邊的小「攻」鈕是普攻(傷害低,用來牽制)、再上面是「防」。爆氣滿了手勢圈外框會亮金光。

2P:按手把任一鍵或小鍵盤 1 即加入(方向鍵移動、小鍵盤 1 攻 / 2 技 / 3 防、4 最強必殺技、6 前衝 / 5 後滑 / 8 9 縱步)。

手把:X 攻、A 單按前衝(A + 搖桿往後 / 上 / 下 = 後滑 / 縱步)、B / RB 防、Y 最強必殺技。

遊戲中:Enter 或「選單」回首頁。
