### 0-1 政治戲仿角色的界線(公開上架,寫死在設計裡)

- 定位:**輕鬆搞笑的諷刺漫畫角色**,兩人用同一把尺(都是「招牌特徵漫畫化 + 荒誕喜劇招式」)。
- 造型只取招牌特徵:髮型、服裝(西裝 / 立領人民裝)、手勢、表情。**體型畫成與其他角色相同的 Q 版標準身材**,不誇張胖瘦、不畫外貌缺陷,不涉及種族、疾病、性、仇恨。
- 招式只做荒誕喜劇:金牆、發文泡泡、握手太久、高爾夫、煙火、鼓掌、拿小本子指導。**不出現**核武、飛彈、軍隊、處決、酷刑、傷亡、真實事件或悲劇、國旗與政治口號文字(含帽子上的字)。
- 遊戲內名稱只用戲仿名,不放本名、不放肖像照片風格,美術維持與全體角色相同的漫畫畫風。
- 我主動調整過的構想與理由:
  - 金正恩戲仿的「火箭」只做**煙火火箭**,落下是彩帶紙花,不做發射台、不做軍事遊行(避免影射飛彈試射與軍事威脅)。
  - 不用「胖」「小胖」之類的稱呼或體型梗(屬人身外貌攻擊)。
  - 川普戲仿的「牆」只做誇張的金色牆與推擠,不寫入任何移民、族群相關文字或圖像。
  - 兩人都不放「被打敗的屈辱演出」等針對個人的羞辱特寫;受擊、倒地與其他角色共用同一套規格。
