# 引擎介面(手機滑動出招改版,引擎層)

> 2026-11-18 引擎層(`js/sim/*`、`js/core/input.js`、`js/net/codec.js`)給 UI / 資料層讀的介面。設計見 `手機滑動出招設計.md`。
> 測試:`tools/step-test.mjs`(月步 / 取消跳躍 / 普攻遞減 / MP / codec / AI),其餘舊測試已對齊新規則。

## 1. 輸入位元組(8 bit)

`BIT = { UP:1, DOWN:2, LEFT:4, RIGHT:8, ATK:16, JUMP:32, DEF:64, STEP:128 }`(`js/core/input.js`)。連線輸入封包本來就是 1 byte,不用改格式。

### 1-1 月步輸入(UI 請用這個)

```js
input.queueStep(src, kind)   // src = 'P1' | 'P2' | 'G1'…;kind = 'fwd' | 'back' | 'up' | 'down'
```

- `fwd` / `back` **依角色面向由引擎判讀**(面向左時 fwd 往左),呼叫端不用知道面向。
- 已有巨集(必殺 / 最強)進行中時,步接在後面;沒有巨集時下一 tick 就生效。
- 編碼(給 AI / 測試直接餵位元組用,`STEP_BYTE`):
  `fwd = 128`、`back = 128|LEFT|RIGHT`、`up = 128|UP|DOWN`、`down = 128|UP|DOWN|LEFT|RIGHT`。
  (左右 / 上下「同時」按在引擎本來就會被抵銷,所以拿來當種類編碼;單一方向位元只是搖桿方向,不改種類,用於連踏中調縱深。)
- 連踏:每一次呼叫 = 一筆手勢。要連踏 4 段就在 ≥ 6 tick 之後再 `queueStep` 一次(見 2-2)。引擎會緩衝請求 6 tick、大招特寫暫停中也保留。

### 1-2 鍵盤 / 手把鍵位(已寫進 `input.js`,devC 請放進說明)

| 動作 | P1 | P2 | 手把 |
|---|---|---|---|
| 前衝 | **E**(或 K 單按) | 數字鍵 6 | A(單按) |
| 後滑 | **Q**(或 K + 往後) | 數字鍵 5 | A + 搖桿往後 |
| 縱步上 / 下 | **R** / **F**(或 K + 上 / 下) | 數字鍵 8 / 9 | A + 搖桿上 / 下 |
| 最強 | U(或 防 + 攻 + K) | 數字鍵 4 | Y |

- **單獨按 K / 手把 A 不再起跳**,改為月步(前衝;加方向鍵變後滑 / 縱步)。前 15 tick 內有按防時 K 是「防 + 方向 + 跳」指令的觸發位(`sp_*_jump` 不變),不會變月步。
- 手機:`touch.js` 對手勢結果呼叫 `queueStep` 即可,不需要經過 K。

### 1-3 必殺 / 最強(不變)

- 必殺:`input.queueMacro('P1', commandMacro(cmd, face))`(`commandMacro` 輸出不變)。
- 最強:`input.queueMacro('P1', ULT_MACRO)`(`ULT_MACRO` 不變,防 + 攻 + 跳 同時)。`BIT.JUMP` 保留為這兩者的內部觸發位。

## 2. 月步規格(實作值,`STEP_SPEC` in `js/sim/fighter.js`)

tick = 1/60 秒。狀態 `S.STEP = 17`(`STATE_NAMES[17] = 'Step'`,動畫表可用 `art.states.step`,沒有就退回待機圖)。

| | 前衝 | 後滑 | 縱步上 / 下 |
|---|---|---|---|
| kind(`f.stepK`) | 1 | 2 | 3 / 4 |
| 起步 / 移動 | 2 / 8 tick | 2 / 10 tick | 2 / 8 tick |
| 位移 | 150 px(18.75 px/tick),朝面向 | 110 px,背向面向,面向不變 | z ∓60 px |
| 單段收招 | 10 tick | 8 tick | 8 tick |
| 步力消耗 | 25 | 20 | 15 |
| 連踏中縱深操控 | 按住上 / 下:每段 z ±24 px | 每段 z ±30 px(3 px/tick × 10 tick) | — |
| 無敵 | 無 | 無;**後滑中被打 = 失衡**:fall +20、硬直 ×1.5 | 無 |

### 2-1 連踏

- 每段第 6 tick 起(含收招)再輸入 = 接下一段,**段與段無間隔**(前衝 4 段 = 600 px / 40 tick)。連續上限 `STEP_CHAIN = 4` 段(前衝後滑可混接;縱步不可接縱步)。
- 連 3 段以上、或步力 < 15 時,**最後一段後收招 16 tick(`STEP_BREATH`)破綻**:不能再踏、不能取消。

### 2-2 取消

- 月步第 6 tick 起(且不在上述 16 tick 破綻中)可直接接 **必殺(commandMacro)/ 最強(ULT_MACRO)**;AI 與玩家同規則。
- 可從待機 / 走 / 跑 / 急停 / **普攻取消窗** 進入月步。防禦、受擊、倒地、起身、暈、空中、必殺中、封招(`silence`)不可。

### 2-3 步力(UI 畫步力條)

```js
import { stepPower, STEP_MAX } from '../sim/fighter.js';
stepPower(f)      // 0~100(浮點)。f.stepP 為定點數(×256),STEP_MAX = 100*256
```

- 停用月步 24 tick(0.4 秒)後每 tick +0.5(= 每秒 30)。起手 100。
- 重生會補滿。連線快照含 `stepP`,客戶端預測世界直接讀 `fighter.stepP`。

## 3. 取消跳躍

- `RULES.noJump = true`(`js/sim/fighter.js`,預設;連線各端一致,不進快照,測試可臨時關)。
- 跳 / 衝刺跳 / 跳攻 / 衝刺跳攻玩家**無法觸發**;招式自帶 `launch`(旋風豬上天等)產生的離地不變。
- `jumpatk` / `dashatk` 招式資料保留不刪(`RULES.noJump = false` 時恢復舊行為,僅供測試)。

## 4. 普攻降傷(引擎)

- 普攻判定:招式標 `basic: true`(`compileChar` 輸出 `moves[x].basic`),或 itr 帶 `basic: true`,或名稱是 `attack1~3 / runatk / jumpatk / dashatk`(三者擇一即可,devB 的資料已標)。
- **遞減**:每個被打者 `nHit` / `nHitT`:3 秒(180 tick)內沒再被普攻打中歸零;同目標第 1~3 下 ×1、第 4~6 下 ×0.5、第 7 下起 ×0.25(最少 1)。**被擋的不計數**。必殺 / 最強 / 射彈不計入、不受影響。
- **被擋**:普攻被正面防住 0 傷害(必殺仍吃 10% 擦傷),`bdef` 照 itr 累積。
- **回 MP**:itr 有 `gain > 0`(帆帆例外)就照資料;否則只有同目標 3 秒內第 1~3 下各 **+4**(合計最多 +12),被擋 0。
- **被打回 MP**:+5(原 +3,`takeHit` 常數)。
- 資料係數(普攻 ×0.4、必殺 ×1.2、cost ×0.7、mpRegen 14、mpStart 300)只在 `data/chars/*.json`,引擎不再乘一次。

## 5. 漫漫龜大地震(震波)

- 新 itr 欄位 `wave: { r, t }`(單位 px / tick):所在招式格(`wait` 應等於 `t`)期間,判定環帶由施放者中心向外擴散,第 k tick 掃過距離 `[r·(k-1)/t, r·k/t)` 的敵人(用 x 距離,縱深以 `zr` 限制)。`manman.json` ultimate:`wave: { r: 700, t: 30 }`、`zr: 240`、`stop: 0`(不能有攻擊方頓幀,否則震波會停住)。
- 不可防(`ult.unblockable`)、**無敵 / 倒地 / 起身的人不吃**(`isInvuln`),翻滾抓時機可躲;一次施放每人只中一次。
- 招式格開始時發事件 `{ t: 'wave', x, y, z, r, n, id }`(畫面可用來畫擴散環;沒接也不影響)。
- 起手 50 tick、波 30 tick、收招 14 tick(frames 7 格,與美術 `ultimate` 7 格對齊)。
