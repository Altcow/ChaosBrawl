## 1. 用語統一與機制說明

以後不分「大招」與「必殺」,一律叫**必殺技**。每位角色 4 招必殺技:3 招用 **MP**(指令 `D+方向+攻/跳`),1 招用**爆氣條**(`D+A+J` 同按,觸控為專屬鈕),後者稱為**最強必殺技**(就是原本的大招)。引擎機制完全不動:爆氣條累積、世界暫停 60 tick、暗幕 + 特寫 + 招名、全場演出冷卻 3 s、每目標傷害上限、被打中後 3 s 保護、房主可關閉,全部照 `角色名單設計.md` 第 2 節。程式識別字(`ultimate`、`ult`、`info.ult`、`art.cutin`)維持英文不改,只改畫面上的中文字(見第 4 節 T1)。

文件內記號:`[有]` = 現有引擎已支援(已讀過程式確認);`[需開發 Dn]` = 第 4 節的新增項;`[資料]` = 只要改角色 json,不用改程式。

**現有引擎能力(已在程式中確認)**:射彈 spawn(含 `vz` 扇形、`pierce` 穿透、`boomerang` 迴力、`chase`、`limit`、`wall`、`zone`)、招式格 `inv` 無敵 / `armor` 霸體 / `turn` 轉身 / `tp` 瞬移到背後 / `counter` / `reflect` / `heal` 回血 / `pull` 吸引 / `mark`+`recall` 回原位 / `buff`、招式 `steer`(招式中可用方向鍵移動,含縱深)/ `launch` / `lock` 鎖定演出、`live`(最強必殺技的無敵窗在這格結束)。**沒有**:射彈拋物線(D4)、延遲爆炸(D5)、特效的垂直位移與結束格(本文件 D19)。

**畫格計算慣例**:角色在畫面上很小(約 40 px),所以一招只畫「起手 / 出手」,收招盡量沿用出手格或通用 40 格。`art.moves` 一個邏輯格只顯示一張圖;要讓長時間的格「動起來」,做法是把 json 的那一格拆成數個等長小格交替兩張圖(命中紀錄以招式序號計,拆格不會多打)`[資料]`,或疊一組循環特效(`art.fx` 會依 rate 循環)。

**格型尺寸**(以 12 格版 1536×1024 的一個格位 ≈ 384×341 為 1 格):
- **窄格** = 1 格(一般姿勢、小物件)
- **寬格** = 橫向 2 格(長武器水平姿勢、騎馬、短光束、環形電弧)
- **特寬格** = 整排 4 格(橫越畫面的長光束、長刀光)
- **特寫格** = 2×2 格,放在下兩排置中(最強必殺技演出用胸上大頭)
