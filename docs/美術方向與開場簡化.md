## 一、角色美術方向

### 1-1 自查:引擎現在要畫哪些狀態

現況事實:
- fighter.js 有 17 個狀態(IDLE…DEAD);每個招式(attack1~3、runatk、jumpatk、dashatk、sp_*、counter)在資料裡都是「起手 / 判定 / 收招」3 個邏輯格 → 美術可以直接對應「每招 2~3 張關鍵姿勢」。
- sprites.js 目前是色塊人形,倒地 / 翻滾靠**整張旋轉**表現;正式圖不沿用這種做法。
- 草案 1-2 的抓取、被抓、持物、投擲、喝珍奶**還沒實作**(沒有 items.js),勝利動作也沒有 → 本輪不畫,列預留。

### 1-2 部件動畫夠不夠用(結論:不夠)

| 範圍 | 部件動畫做不到、必須逐格的部分 | 原因 |
|---|---|---|
| 所有角色 | 倒地、擊飛、翻滾、起身(6~8 格) | 身體換方向或縮成一團,部件只能整組旋轉 = 旋轉硬湊 |
| 阿達 | 機車衝撞 2~3、飛擲便當出手 + 便當射彈 2、熱湯上鉤拳(湯碗+蒸氣)2~3 | 機車、湯碗是大道具,跟身體有前後遮擋 |
| 阿嬤 | 菜籃迴旋摔 3(籃子在身前 / 身後換層)、廣場舞震地 3 + 地面震波、大跳壓空中坐姿 2 | 胖體型、四肢短,關節接縫藏不住;招式範圍寬 140 px |
| 館長 | 飛書出手 2 + 書射彈 2、書牆出現 / 崩塌 3(場地物件,高 80 px)、安靜圈地面圈 1~2 | 抱書姿勢手被書擋住;書牆不是人物部件 |
| 喵影 | 影步消失 / 出現煙 4 + 本體 2、爪擊亂舞迴圈 3~4、裝死翻肚 1 + 反擊 2 | 尾巴、耳朵每個動作都要變形 |

部件能勉強撐住的只有站、走、跑、防、受擊、暈眩,約 **20 格 / 人(約 40%)**;其餘約 30 格本來就要逐格畫。**素材不足:不論選哪種做法,每人至少要補畫約 30 格逐格圖**,部件法省不掉這部分。

### 1-3 兩種做法比較與建議

| | (1) 部件分件圖 + 程式拼接 | (2) 逐格關鍵姿勢圖(建議) |

### 1-4 風格定位與統一規格

**風格**(2026-11-13 改:依使用者截圖 `給GPT\參考\風格參考_小朋友齊打交截圖.webp`,每批必傳)
- Q 版日式動漫小人,頭約占身高 1/3(約 3 頭身)、日常職業、有趣非寫實;細深色外框(不斷線)+ 鮮明配色 + 賽璐璐上色(亮 / 暗兩階為主,可帶少量漸層與高光)。不再用「粗外框兩階平塗」。
- 風險【估算】:細外框縮到螢幕 40 px 高時會變淡,靠剪影與主色辨認;臉部表情(反差梗)在 40 px 只剩約 13 px 的頭,細節看不清,反差梗要靠姿勢與道具表現。
- 每人主色沿用角色資料的 `color` 欄,8 人主色互不相近;**剪影可辨**(塗黑也認得出):阿達 安全帽 + 背後外送箱;阿嬤 燙捲髮 + 菜籃;館長 圓眼鏡 + 抱一疊書;喵影 貓耳 + 長圍巾 + 尾巴。

## 二、開場選單簡化

### 2-1 現況問題

- 單機區一進來:模式 1 + 友軍傷害 1 + 8 座位 × 3 個下拉(種類 11 選項、角色、隊伍)= **26 個控制項**才到「開始」;手機橫向約要捲 2 頁以上【估算】。
- 「友軍傷害」只對分隊有效卻永遠顯示;座位種類把鍵盤 P2、手把 1~4、電腦四級全攤開。
- 連線區:建房者角色固定第一個、加入者隨機,大廳不能選角(room.js);模式借用單機區的下拉,兩區互相牽扯。
- 遊戲中右上 4 顆工具鈕(盒子 / 場景 / 重置 / 選單)前兩顆是開發用。

### 2-2 新手預設流程

開頁 → 角色已預選(上次用的;第一次 = 阿達)→ 按「開始」→ 直接開打。**最少 1 次點擊**。

快速開始內容:大亂鬥、1 真人 + 7 電腦(角色隨機,可重複)、電腦強度「普通」、舞台夜市。所有「更多設定」改過的值存 localStorage,開始鈕文字跟著變(例:「開始(分隊戰 6 人)」),玩家看得出這次會打什麼。

### 2-4 必留與可藏

| 選項 | 處理 | 理由 |
|---|---|---|
| 角色 | **首頁必留** | 唯一每局都可能想改的;一排頭像一點就好 |
| 開始 | **首頁必留,最大** | |
| 連線入口 | 首頁次要鈕 → 獨立面板 | 要網路、步驟多,跟單機混在同頁是現在「複雜」的主因之一 |
| 練習 | 首頁小鈕 | 新手學必殺用,一點直接進木樁 |
| 模式 | 更多設定 | 預設大亂鬥即可;改了會記住 |
| 總人數 | 更多設定 | 預設 8;一個數字取代 8 列「關閉 / 開啟」 |
| 電腦強度 | 更多設定 | 一個全域值取代 8 個各自等級 |
| 隊數、友軍傷害 | 分隊戰才顯示 | 亂鬥時無效;真人自動在 1 隊,電腦平均分配 |
| 每座位種類 / 角色 / 等級 | 「自訂每個座位」第二層 | 進階玩家才需要;現有程式直接搬,不重寫 |
| 魔王等級 | 只在自訂座位 | 草案定位為生存模式 Boss |
| 同機 2P / 手把 | **不用選,按鍵加入** | 首頁偵測到手把或 P2 鍵輸入,自動佔下一座位並顯示「P2 已加入:角色」;省掉 11 選項的座位種類 |
| 盒子 / 場景鈕 | 只在網址帶 `?debug` 時顯示 | 開發用 |
